# Security Policy

## Supported versions

Only the latest commit on `main` is supported. Fixes are not backported.

## Reporting a vulnerability

Please **do not** open a public issue for security problems.

Report them privately through GitHub's
[private vulnerability reporting](https://github.com/burgesQ/manga_manager/security/advisories/new)
(*Security* tab → *Report a vulnerability*). Include the affected package
(`packer`, `editor` or `convertor`), the steps to reproduce and the impact.

You can expect an acknowledgement within a week.
